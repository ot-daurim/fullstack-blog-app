# Fullstack Blog App

Учебный проект блога на React. Сейчас в приложении реализованы страницы Home, About и Articles, список статей с краткими описаниями, страницы отдельных статей и обработка неизвестного маршрута. Данные статей хранятся в проекте как статический массив — серверная часть пока не подключена.

## Что реализовано

1. **Создана основа проекта** — приложение инициализировано с помощью Vite, настроены React и точка входа.
2. **Добавлены страницы приложения** — созданы страницы Home и About, а также страницы списка статей и отдельной статьи.
3. **Настроена навигация** — добавлена общая панель ссылок, а компонент Layout размещает её рядом с содержимым текущей страницы.
4. **Подключён React Router** — настроены маршруты `/`, `/about`, `/articles` и `/articles/:name`.
5. **Добавлены демонстрационные статьи** — в массиве данных находятся статьи о React, Node.js и MongoDB.
6. **Реализован список статей** — на странице `/articles` отображаются названия, короткие фрагменты текста и ссылки на статьи.
7. **Добавлены страницы статей и обработка неизвестных маршрутов** — адреса вида `/articles/learn-react` показывают статью, а для несуществующего маршрута предусмотрена страница Not Found.

## Технологии

- React
- React Router
- Vite
- JavaScript
- CSS

## Запуск проекта

Требуется установленный Node.js и npm.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который Vite покажет в терминале (обычно `http://localhost:5173`).

## Проверка проекта

```bash
npm run lint
npm run build
```
